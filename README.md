# VN Drinks🍻

Catálogo de bebidas com carrinho e pedidos pelo WhatsApp, adaptado para computador e celular.

Site: **https://viniciosalvees.github.io/VN-Drinks/**

Para abrir a prévia local:

```sh
npm run dev
```

Execute o comando na raiz deste repositório e abra **http://127.0.0.1:4173**. É necessário Node.js; não há dependências para instalar. Para verificar o projeto, execute `npm test`.

- [Guia de edição, logo, fotos, produtos e publicação](docs/GUIA.md)
- [Catálogo e preços editáveis](dist/js/catalog.js)
- [Página principal](dist/index.html)
- [Estilos e animações](dist/css/styles.css)

O GitHub Pages publica automaticamente o conteúdo de `dist/` após alterações na branch `main`. O fluxo também executa os testes em pull requests. A configuração fica em [pages.yml](.github/workflows/pages.yml).

Confira os dados do catálogo e os avisos de demonstração antes de receber pedidos.
